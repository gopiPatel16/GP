Stock Data Analysis with Python 

This project analyzes Tesla and GameStop stock performance using Python. It retrieves historical stock prices with yfinance, extracts revenue data through web scraping using BeautifulSoup and pandas, cleans and processes the datasets, and visualizes stock price and revenue trends. The project demonstrates data collection, web scraping, data preprocessing, and interactive plotting techniques, making it a practical example of financial data analysis and visualization using Python libraries such as Plotly, Requests, and Pandas.
